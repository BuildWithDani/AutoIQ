# Public Assets

Place static assets here that should be served directly:

- `logo.png` - Application logo (will appear in the header)
- `favicon.ico` - Browser favicon (optional)

## Logo Requirements

- **Format**: PNG
- **Size**: 256x256 or larger (will be scaled to 40x40 in header)
- **Background**: Transparent or white recommended

## Adding Your Logo

1. Place your logo file as `logo.png` in this folder (`frontend/public/`)
2. Or place it in the root `assets/` folder and it will be copied during build
3. The logo will automatically appear in the app header
